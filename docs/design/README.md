# WebUI 视觉概念

本目录保存 WebUI 实现前生成的桌面端和移动端视觉概念。生成工具为 Codex 内置 Image Gen，图片只作为构图、色彩和层级参考；生产棋盘与控件由 React、CSS 和 SVG 原生实现。

## 最终提示词组

桌面端：

> 为“弈境 GOMOKU AI”设计一张 1440×1000 的高保真桌面 Web 游戏界面概念图。风格是现代东方棋院与高端编辑设计：象牙纸背景、墨黑文字、蜂蜜色木棋盘、朱砂红点缀、克制纸张纹理。左侧为大尺寸 15×15 五子棋棋盘，右侧为紧凑控制面板，包含当前回合、人机对战与 AI 对 AI、执子、Alpha-Beta v5、1–10 难度、悔棋、重新开始、展开的着法记录和 WebAssembly 本地计算说明。中文文案清晰、留白充足、无照片、无 3D、无渐变、无传统网页导航栏。

移动端：

> 为同一“弈境 GOMOKU AI”生成 390×844 的高保真移动端 Web 游戏界面概念图。延续象牙纸、墨色、蜂蜜木和朱砂红的现代东方编辑风格。顶部精简品牌与说明按钮，先显示当前回合，再显示占满可用宽度的正方形 15×15 棋盘，棋盘下是悔棋和重新开始，随后是纵向设置；着法记录默认折叠。所有控件适合触控，不横向滚动，不使用照片、3D 或渐变。

生成概念时产品范围原为人机对战与 AI 对 AI；随后按需求在实现中增加了“同一设备双人对战”。
