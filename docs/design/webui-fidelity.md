# WebUI 视觉对照记录

## 关键特征

| 特征 | 概念图 | 实现 |
| --- | --- | --- |
| 页面结构 | 桌面棋盘在左、设置在右；移动端纵向排列 | 同结构，断点为 900px |
| 色彩材质 | 象牙纸、墨色、蜂蜜木、朱砂红 | 使用 CSS 色彩变量、细线和轻纸纹理实现 |
| 字体层级 | 编辑式大标题、紧凑说明、清晰数字 | 中文 serif 标题搭配系统 sans 正文 |
| 棋盘表现 | 木色 15×15 棋盘、星位、黑白棋子 | SVG 原生绘制，支持键盘焦点和精确点击 |
| 控件密度 | 分段模式、执子、算法、难度、主操作、棋谱 | 全部实现；桌面棋谱默认展开，移动端默认折叠 |

## 有意差异

- 增加用户要求的“同一设备双人对战”，概念图原来的两段模式扩展为三段。
- 初始棋盘保持空局面，不复制概念图中的演示棋谱，以免用户误以为已有对局。
- 棋盘坐标按项目既有规则从上到下显示 `1–15`，不沿用概念图中仅用于构图的反向标号。
- 棋盘、棋子和品牌标记使用 SVG/CSS，而不是概念图位图，以保证清晰度、可访问性、命中测试和响应式缩放。
